## 5. Bugs & Fixes

### Bug 1: Force-with-lease Rejection (GitHub Actions)
**Symptom**: `--force-with-lease` failed with "stale info" error  
**Root Cause**: Workflow hadn't fetched remote branch state before pushing  
**Fix**: Changed to `--force` since this is a true mirror where target should always match source

### Bug 2: Boolean Flag Not Working (Hello CLI)
**Symptom**: Both `--false` and `--true` flags produced uppercase "HELLO" output  
**Root Cause**: `process.argv[3]` returns a string; any non-empty string (including `"false"`) is truthy in JavaScript  
**Fix**: Changed from value-based flags to presence-based `--shout` flag (standard CLI convention)

### Bug 3: Jest Not Found in CI
**Symptom**: GitHub Actions failed with `sh: 1: jest: not found`  
**Root Cause**: Jest was installed locally but not listed in package.json devDependencies; `npm ci` didn't install it  
**Fix**: Added `"jest": "^29.7.0"` to devDependencies and updated package-lock.json

### Bug 4: Files Missing After Branch Switch
**Symptom**: CLI files disappeared after switching from feat/hello-cli to development  
**Root Cause**: Files created on feature branch don't exist on other branches until merged  
**Fix**: Proper branch awareness and git stash workflow to move changes

## 6. What I Learned

### GitHub Actions & CI/CD
- How to configure GitHub Actions workflows with triggers, jobs, and steps
- SSH authentication in CI/CD using deploy keys stored as secrets
- The difference between `--force` and `--force-with-lease` for git push
- `persist-credentials: false` is crucial when mixing HTTPS checkout with SSH push
- `npm ci` is stricter than `npm install` and requires proper package.json

### JavaScript & CLI Development
- **JavaScript truthy values**: Any non-empty string is truthy, including `"false"` and `"0"`
- **CLI conventions**: Presence-based flags (`--flag`) are standard for booleans, not value-based (`--flag=true`)
- **Exit codes**: 0 = success, 1 = error; critical for scripting and automation
- **Error output**: Error messages go to stderr, not stdout

### Git & Branch Management
- Files created on feature branches don't exist on other branches until merged
- `git stash` is useful for moving uncommitted changes between branches
- Local node_modules can mask missing package.json dependencies
- CI environment is clean and exposes configuration issues that work locally

### Testing & Documentation
- Test coverage should include both positive and negative cases
- Error handling should provide clear messages and usage instructions
- Documentation should include usage examples AND error cases
- Review packets help capture learning and debugging process
